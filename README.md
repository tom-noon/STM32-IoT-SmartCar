# 智能小车及其控制APP开发

## 项目简介
本项目基于 STM32F103 与 EMQX 云平台，实现温湿度采集、超声波避障、OLED 本地显示；安卓 APP（Uniapp+Vue）支持 MQTT 远程控制与蓝牙直连，可实时监控数据、调节电机转速方向及 LED 开关。

## 硬件平台
- 主控：STM32F103C8T6
- 传感器：DHT11（温湿度）、HC-SR04（超声波）
- 执行：L298N 电机驱动、LED
- 显示：0.96寸 OLED (I2C)
- 通信：ESP8266 (MQTT)、HC-05 (蓝牙)

## 软件架构
- **嵌入式端**：STM32CubeMX + Keil，多任务轮询，串口解析 AT 指令
- **云平台**：EMQX 公共 MQTT 服务器
- **移动端**：Uniapp + Vue，支持 MQTT.js 和蓝牙 API

2. 移动端：HBuilderX 导入项目，编译运行到安卓手机
